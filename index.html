01 · Featured Project
SpendMind — AI Personal Finance Assistant
“Chat with your bank statement — ask about your money in plain English and get exact, SQL-verified answers, never a hallucinated number.”
SpendMind is an AI-powered personal finance assistant delivered through a Telegram bot and an Angular web dashboard. Upload a CSV, PDF statement, or forward a bank SMS — it auto-categorizes every transaction and answers natural-language questions about your spending. Its defining principle: the database does the math, the LLM only explains.
Highlights
DB does the math, LLM only explains — every numeric answer runs through parameterized SQL, so totals are always correct.
Agentic RAG — a Claude agent chooses between summary, transaction-search, and advice tools in a real multi-tool loop, with pgvector similarity search for cited financial advice.
Multi-format ingestion — CSV, PDF statements, and bank SMS through one pipeline, with cost-smart categorization (memory → rules → LLM).
Injection-resistant & multi-tenant — user_id is injected server-side, never controlled by the LLM.
18/18 eval score — a scored suite covering exact-number accuracy, out-of-scope handling, and prompt injection.

02 · Currently Building
ImpactIQ — AI-Powered Change Impact Analysis
“What will this change break — before I write a single line of code?”
ImpactIQ is a developer tool that predicts the blast radius of a proposed code change. Describe a change in plain English and it analyzes the codebase's dependency graph to return the files and modules likely to be affected — each backed by concrete evidence — plus a risk assessment and recommended tests. It surfaces hidden and indirect dependencies upfront, before they become production regressions.
What makes it different — evidence before AI claims
Deterministic facts, AI judgment — graph traversal establishes what provably depends on what; the LLM only interprets and explains, sharply reducing hallucination.
Traceable evidence — every prediction points to the exact file, symbol, import, or dependency path. If evidence is missing, it says so instead of inventing it.
Measured, not vibes — an evaluation harness scores precision/recall against hand-labeled cases, so accuracy is a number.
Built so far (v1)
Architecture extraction from Mermaid diagrams, architecture images (Claude Vision), or SQL schemas.
Agentic impact analysis — a multi-pass loop where Claude calls deterministic graph tools (dependency tracing, cycle detection, blast-radius estimation, safe-deploy ordering).
Structured, Zod-validated impact reports: affected modules with severity, hidden dependencies, test checklists, deployment risks.
Building now (v2 — real-code grounding)
Repository ingestion with safe, sandboxed indexing (never executes code) and an AST-based dependency graph via the TypeScript Compiler API.
Evidence-grounded analysis over a bounded codebase slice, with output validation that rejects any finding whose paths, symbols, or lines don't exist in the repo.
